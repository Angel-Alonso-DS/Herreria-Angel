# Herreria-Angel

## Descripcion
Es una pagina web estatica que muestra el portafolio de una herreria para poder atraer mas clientes y tener una manera mas sencilla de mostrar su trabajo

## Antecedente
Actualmente el portafolio se maneja a traves de fotografias tomadas con el celular y almacenadas en el mismo despositivo y cuando se requiere mostrar un portafolio a algun cliente se tiene que buscar en los archivos las imagenes referenter a su trabajo

## Objetivo General
El objetivo es Desarrollar una pagina web que mustre el portafolio y los servicios de la herreria en un plazo no mayor a un mes utilziando fotografias y una breve descripcion de los tipos de trabajos que se maneja desplegada en un servidor gratuito con un dominio personalizado

### Objetivos Especificos

- Implementar una pantalla principal que contendra una breve descripcion de la herreria y una imagen estatica de fondo
- Implementar una galerria de fotografias de los trabajos que se han realizado, mostrando la fotografia junto con un titulo
- Implementar una seccion de 'Nosotros' para describir los servicios de la herreria
- Implementar una seccion de contacto con el numero telefonico y correo en el cual puedan contactar a la herreria ademas de mostar el horario en la que la herreria labora
- Implementar un boton flotante que se muestre en la esquina inferiror derecha de WhatsApp para poder contactar falcilmente los servicios sin tener que recorrer toda la pagina para acceder al contacto, este boton abrira un chat en WhatsApp para conversar
- Implementar una barra de navegacion superior simpre visible para poder navegar con botones en las distintas secciones de la pagina

## Alcances

- Desarrolalr una pagina web estatica con informacion predefinida
- Galeria con imagenes reales del herrero
- Arquitectura preparada para posible desarrollo de un servidor con base de datos
- Estilo minimalista con animaciones suabes

## Limitaciones

- En esta etapa no se usan bases de datos ni servicios externos para poder almacenar y gestionar las imagenes
- No se implementara en esta etapa un formulario de contacto con servico de correo
- No se manejara videos en la pagina web
