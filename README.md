# Herreria-Angel

## Descripción

Es una página web estática que muestra el portafolio de una herrería para poder atraer más clientes y tener una manera más sencilla de mostrar su trabajo.

## Antecedente

Actualmente, el portafolio se maneja a través de fotografías tomadas con el celular y almacenadas en el mismo dispositivo y, cuando se requiere mostrar un portafolio a algún cliente, se tiene que buscar en los archivos las imágenes referentes a su trabajo.

## Objetivo general

El objetivo es desarrollar una página web que muestre el portafolio y los servicios de la herrería en un plazo no mayor a un mes, utilizando fotografías y una breve descripción de los tipos de trabajos que se manejan, desplegada en un servidor gratuito con un dominio personalizado.

### Objetivos específicos

- Implementar una pantalla principal que contendrá una breve descripción de la herrería y una imagen estática de fondo.
- Implementar una galería de fotografías de los trabajos que se han realizado, mostrando la fotografía junto con un título.
- Implementar una sección de 'Nosotros' para describir los servicios de la herrería.
- Implementar una sección de contacto con el número telefónico y correo en el cual puedan contactar a la herrería, además de mostrar el horario en el que la herrería labora.
- Implementar un botón flotante que se muestre en la esquina inferior derecha de WhatsApp para poder contactar fácilmente los servicios sin tener que recorrer toda la página para acceder al contacto. Este botón abrirá un chat en WhatsApp para conversar.
- Implementar una barra de navegación superior siempre visible para poder navegar con botones en las distintas secciones de la página.

## Alcances

- Desarrollar una página web estática con información predefinida. Galería con imágenes reales del herrero.
- Arquitectura preparada para posible desarrollo de un servidor con base de datos
- Estilo minimalista con animaciones suaves.

## Limitaciones

- En esta etapa no se usan bases de datos ni servicios externos para poder almacenar y gestionar las imágenes.
- No se implementará en esta etapa un formulario de contacto con servicio de correo.
- No se manejarán videos en la página web.
